## 📊 API接口快速参考

### 社区相关API

#### 1. 获取帖子列表
```
GET /api/community/posts?page=1&size=10
```

#### 2. 搜索帖子
```
GET /api/community/posts/search?keyword=关键词
```

#### 3. 获取帖子详情
```
GET /api/community/posts/{id}
```

#### 4. 发布帖子
```
POST /api/community/posts
Body: { title, content, images }
```

#### 5. 点赞帖子
```
POST /api/community/posts/{id}/like
```

#### 6. 评论帖子
```
POST /api/community/posts/{id}/comments
Body: { content }
```

### 商店相关API

#### 1. 获取商品列表
```
GET /api/shop/products?page=1&size=20
```

#### 2. 搜索商品
```
GET /api/shop/products/search?keyword=关键词
```

#### 3. 获取商品详情
```
GET /api/shop/products/{id}
```

#### 4. 按分类筛选
```
GET /api/shop/products?category=分类名称
```
