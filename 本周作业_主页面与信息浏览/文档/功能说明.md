# 主页面与信息浏览功能详细说明

## 📌 功能模块概览

本作业包含DeepTalk项目中的核心功能模块,主要涉及主页面展示和信息浏览功能。

---

## 1. 主页面 (Home.vue)

### 功能描述
主页面是用户登录后的首页,提供系统的核心功能入口和概览信息。

### 主要功能
- **欢迎界面**: 展示用户信息和系统介绍
- **快速导航**: 提供到各个功能模块的快捷入口
- **统计信息**: 显示用户学习数据和系统状态
- **推荐内容**: 展示推荐的学习资源和社区内容

### 技术特点
- 响应式布局设计,适配不同屏幕尺寸
- 使用Vue 3 Composition API
- 集成Ant Design Vue组件库
- 数据实时更新

### 用户交互流程
```
用户登录 → 进入主页 → 查看推荐内容 → 选择功能模块 → 进入对应页面
```

---

## 2. 社区浏览功能 (Community.vue)

### 功能描述
社区模块是用户交流学习经验的平台,用户可以浏览帖子、发表内容、互动交流。

### 主要功能

#### 2.1 帖子浏览
- **列表展示**: 以卡片形式展示所有帖子
- **分页加载**: 支持分页浏览,提高加载速度
- **排序功能**: 
  - 按时间排序(最新/最早)
  - 按热度排序(点赞数)
  - 按回复数排序

#### 2.2 搜索功能
- **关键词搜索**: 支持标题和内容搜索
- **实时搜索**: 输入即搜索,无需点击按钮
- **搜索历史**: 保存最近的搜索记录

#### 2.3 帖子互动
- **点赞功能**: 一键点赞,可取消点赞
- **评论功能**: 查看和发表评论
- **分享功能**: 分享到社交平台

#### 2.4 发帖功能
- **富文本编辑器**: 支持文本格式化
- **图片上传**: 支持多图上传
- **标签系统**: 为帖子添加分类标签
- **草稿保存**: 自动保存草稿

### 数据结构
```typescript
interface Post {
  id: number;
  title: string;
  content: string;
  author: Author;
  createdAt: Date;
  likes: number;
  comments: number;
  tags: string[];
  images?: string[];
}
```

### 业务流程
```
浏览帖子列表 → 搜索/筛选 → 点击帖子 → 查看详情 → 互动(点赞/评论)
              ↓
         发布新帖子 → 编辑内容 → 添加图片/标签 → 发布
```

## 3. 帖子详情功能 (PostDetail.vue)

### 功能描述
展示单个帖子的完整内容,包括作者信息、正文、评论区等。

### 主要功能

#### 3.1 内容展示
- **帖子信息**: 标题、作者、发布时间、浏览量
- **正文内容**: 支持富文本显示
- **图片展示**: 图片预览和放大查看
- **标签显示**: 展示帖子相关标签

#### 3.2 互动区域
- **点赞功能**: 
  - 显示当前点赞数
  - 点赞/取消点赞动画效果
  - 防止重复点赞
- **收藏功能**: 收藏到个人收藏夹
- **分享功能**: 生成分享链接

#### 3.3 评论系统
- **评论列表**: 展示所有评论
- **评论排序**: 按时间或热度排序
- **发表评论**: 
  - 支持文本和表情
  - @功能提及其他用户
  - 回复特定评论
- **评论互动**: 点赞评论

#### 3.4 作者信息
- **头像和昵称**: 显示作者基本信息
- **关注按钮**: 关注/取消关注作者
- **查看主页**: 跳转到作者个人主页

### 技术实现
```typescript
// 获取帖子详情
const fetchPostDetail = async (postId: number) => {
  try {
    const response = await CommunityAPI.getPostById(postId);
    post.value = response.data;
    loadComments(postId);
  } catch (error) {
    message.error('加载帖子失败');
  }
};

// 点赞处理
const handleLike = async () => {
  if (isLiked.value) {
    await CommunityAPI.unlikePost(postId);
  } else {
    await CommunityAPI.likePost(postId);
  }
  isLiked.value = !isLiked.value;
  updateLikeCount();
};
```

## 4. 商店浏览功能 (Shop.vue)

### 功能描述
商店模块提供学习资源和虚拟商品的浏览和购买功能。

### 主要功能

#### 4.1 商品展示
- **商品列表**: 网格布局展示所有商品
- **商品卡片**: 
  - 商品图片
  - 名称和价格
  - 评分和销量
  - "购买"按钮

#### 4.2 分类筛选
- **分类导航**: 
  - 学习资源
  - 课程包
  - 虚拟道具
  - 会员服务
- **价格筛选**: 按价格区间筛选
- **评分筛选**: 按评分高低筛选

#### 4.3 搜索功能
- **商品搜索**: 搜索商品名称和描述
- **热门搜索**: 显示热门搜索关键词
- **搜索建议**: 输入时提供搜索建议

#### 4.4 商品详情
- **详细信息**: 
  - 商品介绍
  - 使用说明
  - 用户评价
- **购买流程**: 
  - 选择规格
  - 加入购物车
  - 立即购买
  - 确认订单

#### 4.5 购物车
- **添加商品**: 批量添加到购物车
- **数量调整**: 增加或减少商品数量
- **价格计算**: 实时计算总价
- **结算功能**: 跳转到支付页面

### 数据结构
```typescript
interface Product {
  id: number;
  name: string;
  description: string;
  price: number;
  image: string;
  category: string;
  rating: number;
  sales: number;
  stock: number;
}

interface CartItem {
  product: Product;
  quantity: number;
}
```

### 业务流程
```
浏览商品列表 → 筛选/搜索 → 查看商品详情 → 加入购物车/立即购买
                                            ↓
                                      确认订单 → 支付
```

## 5. 导航栏组件 (Navbar.vue)

### 功能描述
全局导航栏,提供快速访问各个功能模块的入口。

### 主要功能

#### 5.1 导航菜单
- **主要菜单项**: 
  - 首页
  - 社区
  - 商店
  - 练习
  - 匹配对战
- **子菜单**: 部分菜单项展开显示子选项
- **路由跳转**: 点击菜单项跳转到对应页面

#### 5.2 搜索功能
- **全局搜索**: 搜索帖子、商品、用户
- **搜索框**: 
  - 支持快捷键(Ctrl+K)
  - 实时搜索建议
  - 历史搜索记录

#### 5.3 用户中心
- **用户信息**: 
  - 头像
  - 用户名
  - 积分/等级
- **下拉菜单**: 
  - 个人主页
  - 设置
  - 退出登录

#### 5.4 通知中心
- **消息提醒**: 
  - 系统通知
  - 评论回复
  - 点赞提醒
- **未读标记**: 显示未读消息数量
- **消息列表**: 展开查看消息详情

#### 5.5 主题切换
- **亮色/暗色模式**: 切换界面主题
- **自定义配色**: 选择主题颜色

### 技术实现
```typescript
// 路由导航
const navigateTo = (path: string) => {
  router.push(path);
};

// 搜索处理
const handleSearch = (keyword: string) => {
  router.push({
    path: '/search',
    query: { q: keyword }
  });
};

// 退出登录
const logout = () => {
  localStorage.removeItem('token');
  router.push('/login');
};
```
